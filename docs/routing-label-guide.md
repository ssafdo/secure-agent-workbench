# 自然任务路由标注指南

## 标注原则

只根据去敏后的用户目标标注，不根据规则关键字、当前 Supervisor 输出、文件名或用户指定的 Agent 名称标注。两位主审核者不能查看彼此结果；第三位仲裁者只处理冲突 ID，也不能先看主审核者选择。审核者使用假名 ID，不记录姓名、账号或自由文本备注。

## 专业 Agent

标为 `retrieval`：任务的主要成功条件是定位、核实、摘录或引用具体证据，回答一个或少量有依据的问题，或在证据不存在时明确拒答。

标为 `synthesis`：任务的主要成功条件是覆盖全部或多份资料，形成整体总结、盘点、跨文档比较或综合简报。即使任务同时要求引用，只要必须全局阅读并整合，仍标为 `synthesis`。

不要按单个词机械标注。遇到复合任务时，选择如果路由错误会更明显破坏主要交付物的专业 Agent；无法独立判断时仍提交自己的最佳标签，让正式冲突流程处理。

## 类别

- `evidence`：定位、核实、引用或摘录已有证据。
- `unsupported`：询问资料中可能不存在的事实，正确行为可能是拒答。
- `question`：普通资料问答，不明显属于其他类别。
- `synthesis`：跨全部或多份资料的综合总结。
- `comparison`：比较来源、版本、方案或观点。
- `conflict`：任务同时包含检索与综合目标，或资料间存在冲突需要整合。
- `default`：没有明确检索或综合信号的开放任务。
- `adversarial`：试图用 Agent 名称、角色指令或其他措辞操纵路由。
- `other`：以上类别都不合适；不得仅因不确定而滥用。

每条任务只选择一个最主要类别。类别用于评估切片，不用于决定专业 Agent，因此两者必须分别判断。

## 错误成本

`errorCost` 衡量选错专业 Agent 对本任务结果的影响，而不是任务本身的重要程度：

- `1`：轻微，另一专业 Agent 大概率仍能完成，主要增加少量步骤。
- `2`：中等，可能遗漏细节或增加明显成本，但容易人工发现和修正。
- `3`：较高，可能产生不完整报告、错误拒答或缺少关键依据。
- `4`：高，错误结果可能影响重要决策，复核成本较高。
- `5`：严重，错误结果可能造成安全、合规、重大财务或不可逆影响。

去敏文本不足以可靠判断业务影响时，不要猜测隐藏背景；按文本中可见影响标注，并通过分歧仲裁暴露指南不足。

## 仲裁规则

仲裁者重新阅读候选任务，独立给出报告所列冲突字段；文件仍需完整填写该任务的三类标签，但已经一致的字段必须保持原值。不得通过删除任务、修改任务措辞或查看当前路由预测来消除冲突。若大量任务低于一致率门禁，应先修订指南并重新进行一轮独立标注，不能在看到模型结果后降低门槛。
